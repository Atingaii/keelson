# 工程回归证据

这里保存本轮整改过程中已有的原始 TAP 输出，包括失败的集成运行和对旧实现的反例测试。`2026-09-20-local/manifest.json` 记录每个文件的 SHA-256、字节数、原日志修改时间和直接解析的 TAP 计数；修改时间不是独立可信时间戳。

这些历史日志没有统一记录运行时完整 Git 指纹，不能用于证明最终提交通过。具体修复、已知版本和复核范围见项目变更的 `ledger.md` 及 Git 历史；最终完整检查另外生成当前代码与契约绑定的记录，并通过远程 CI 复跑。
