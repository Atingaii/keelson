# Roadmap

## Now
0.3.x has one runtime authority under `.keelson/`: `workflow.md` is the always-applicable operating kernel and `skill/` is the canonical task router plus on-demand references. Host-known files are discovery shims only, so supporting more agents does not multiply Keelson guidance. Human project state, specs, rules, and changes remain beside that runtime under the same readable project directory.

## Next
- Continuous-evolution test: several changes in one project with session breaks, a requirement revision, a parallel branch, and a merge conflict; compare against a bare agent.
- Codex end-to-end run when the account limit lifts; exercise more `convention` platform adapters and promote only observed/documented discovery paths to higher confidence.
- Retro thresholds tuned on real ledgers rather than guesses.

## Later
- Per-tool adapters beyond discovery files, only where a tool offers a hook or context mechanism that adds measurable value without duplicating canonical guidance.
