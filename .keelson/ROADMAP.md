# Roadmap

## Now
0.2.0: the long-lived-project model. Three status dimensions, decision states, acceptance mapping, evidence fingerprints, handoffs, shared-contract exposure, existing-material references. Done when the demo project has run a spec change through clarify → build → check --record → handoff → resume → land on Claude Code, and the same entry path is confirmed on Codex.

## Next
- Continuous-evolution test: several changes in one project with session breaks, a requirement revision, a parallel branch, and a merge conflict; compare against a bare agent.
- Registry entries for Codex, Cursor, and OpenCode once their alias conventions are stable.
- Retro thresholds tuned on real ledgers rather than guesses.

## Later
- Per-tool adapters beyond files the tool already reads, only where a tool offers a hook or context mechanism worth using.
