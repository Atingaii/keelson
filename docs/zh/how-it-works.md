# 工作原理

项目事实和变更保存在 `.keelson/`，本机密钥、信任与会话保存在 Git 私有目录。默认初始化仅创建精简资料和宿主入口；`keelson guide` 从安装包读取指导，显式 `--vendor` 才复制指导。Hook 调用已安装的 `keelson hook`，不执行仓库内复制的 hook 脚本。

`ask` 管理带归属、依赖、状态和依据的决策。`check` 记录真实执行结果及代码、契约摘要。`land` 检查验收和证据门槛，折叠规格并归档签名记录，写入中断可以恢复。

规格支持旧 h2 需求和 嵌套的 Requirements/h3 形式，围栏中的标题不算结构；合并需要保留未知章节。CLI 的测试证明结构和机制，不能证明所有真实宿主的行为相同。
