# 协作

提交团队需要的项目知识和变更证据，公开前检查日志是否包含敏感输出。本机密钥、信任及会话已位于 Git 私有目录，无需添加忽略规则。

独立修改使用独立 Git worktree。Codex 会话使用 `CODEX_THREAD_ID`；没有宿主身份时可显式设置 `KEELSON_SESSION_ID`，歧义不能被静默猜测。用 `doctor --session --json` 查看实际状态。

`handoff` 用于人员或机器交接。接收机器必须重新执行本机检查，复制来的签名本身不授权完成。并行修改同一契约时，先协调差量、接受真实的基线变化，再重新检查。[完整说明](../collaboration.md)。
