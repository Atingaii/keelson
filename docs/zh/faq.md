# 常见问题

**需要忽略 .keelson 吗？** 不需要。提交事实、决策和可审阅证据；私钥、信任和会话状态留在项目数据之外。不修改 .gitignore。

**签名证明代码正确吗？** 不能。它绑定记录和日志，不证明测试充分、命令无害、作者身份，也无法抵御同一用户权限下的恶意进程。详见[验证边界](verification.md)。

**检查为何 stale？** 代码、验收、决策、配置、spec 或规则改变了。需要重跑完整检查，手写 Verify 不会清除门禁。

**会重复问已回答的问题吗？** ask 保存答案、依据和依赖，显式 reopen 并给出原因才能重开。代理可调查的事实不进入用户队列。

**无人回答怎么办？** 继续独立工作，必要时记录可逆假设。未解决或假设中的结构化决策阻止正常落地；已有明确授权仍然有效。

**所有宿主都真实测过吗？** 没有。Codex 会话标识已本地验证；其他宿主的注册表与夹具测试不等于真实端到端验证。参见[平台能力](../platforms.md)。

**land 发布或部署吗？** 不会。它处理本地契约、归档和状态；推送、发布、部署是独立授权动作。

**日志在哪里？** 带签名证据的变更在 changes/archive 中保留公开密钥和日志，不含私钥。提交前审阅日志内容。

**如何卸载？** uninstall 保留项目事实，--purge 明确删除项目数据。ablate/restore 可逆暂存和恢复集成。
